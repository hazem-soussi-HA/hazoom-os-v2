# HAZOOM OS — Ethical Terms of Use

## Core Principles

### 1. Positive Impact
HAZOOM OS is designed to empower developers, educators, and creators. All use must align with positive, constructive purposes.

### 2. Privacy First
- No user data is collected or transmitted
- All AI agents operate locally in the browser
- No telemetry, no tracking, no analytics
- The system works completely offline

### 3. Open Source Ethics
- Free to use, modify, and distribute
- Attribution appreciated but not required
- Commercial use permitted under MIT license
- Contributions must maintain ethical standards

### 4. Prohibited Uses
The following uses are strictly prohibited:
- Surveillance or monitoring of individuals without consent
- Creating malware, exploits, or harmful software
- Harassment, bullying, or intimidation
- Any activity that violates local, national, or international law
- Military or weapons applications
- Discrimination or hate speech promotion

### 5. AI Agent Ethics
The built-in AI agents (Ox Alpha, Owl, Doctor, Hunter, Lynx) operate under these principles:
- Agents provide information, not directives
- All agent responses are transparent and explainable
- Agents respect user autonomy and decision-making
- No data persistence beyond the current session
- Agents cannot modify system files without explicit user action

### 6. Community Standards
- Be respectful in all interactions
- Share knowledge freely
- Help others learn and grow
- Report issues constructively
- Celebrate diverse perspectives

### 7. Environmental Responsibility
- The system is optimized for low resource usage
- Minimal network bandwidth required
- Efficient code practices reduce energy consumption

## Acceptance

By using HAZOOM OS, you agree to these ethical terms. Violations may result in:
- Loss of community support
- Removal from distribution channels
- Legal action where applicable
