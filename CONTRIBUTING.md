# Contributing to HAZOOM OS

Thank you for your interest in contributing! HAZOOM OS is a community project built on ethical foundations.

## How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/hazem-soussi/hazoom-os.git
cd hazoom-os
npm install
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes
- Follow existing code style
- Test your changes locally with `npm start`
- Ensure no performance regressions

### 4. Commit
```bash
git commit -m "feat: add your feature description"
```

### 5. Push & PR
```bash
git push origin feature/your-feature-name
```

## Code Standards

- **JavaScript**: ES2020+, no external dependencies (vanilla JS)
- **CSS**: Use CSS variables from :root
- **HTML**: Semantic, accessible
- **Files**: Keep under 200KB per file
- **Performance**: Test on low-end devices

## Ethical Requirements

All contributions must:
- ✅ Be constructive and positive
- ✅ Respect user privacy
- ✅ Maintain accessibility
- ✅ Follow the MIT license
- ✅ Include proper attribution for borrowed code

Contributions that violate ethical terms will be rejected.

## Reporting Issues

- Use GitHub Issues
- Include steps to reproduce
- Include browser/device info
- Be respectful and constructive

## Feature Requests

- Open a GitHub Issue with "feature" label
- Explain the use case
- Describe expected behavior
- Consider implementation complexity
